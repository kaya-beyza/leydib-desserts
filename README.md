# LeydiB Desserts - Digital Menu Application

**LeydiB Desserts**, Angular framework'ü kullanarak geliştirdiğim ilk profesyonel Front-End çalışması.  
Butik bir tatlı dükkanı kurgulanarak geliştirilen bu çalışma, kullanıcıların ürünleri inceleyebildiği ve kategorilere göre filtreleyebildiği bir dijital menü arayüzü sunar.

## Öne Çıkan Özellikler

- **Dinamik Kategori Filtreleme**  
  Angular Signals kullanılarak anlık state güncellemeleri ile performanslı filtreleme deneyimi.

- **Bileşen Tabanlı Mimari**  
  Her ürün için yeniden kullanılabilir ve modüler component yapısı.

- **Detaylı Ürün Görüntüleme**  
  Ürünlere özel detay kartları ile kullanıcı dostu inceleme deneyimi.

- **Responsive Tasarım**  
  Mobile-First yaklaşım ile tüm cihazlara uyumlu arayüz.

- **Modern Angular Yapıları**  
  Standalone Components ve Signals gibi Angular 21 özelliklerinin aktif kullanımı.

---

## Kullanılan Teknolojiler

- **Front-End:** Angular 21  
- **Styling:** Tailwind CSS  
- **Programlama Dili:** TypeScript  
- **State Management:** Angular Signals  

---

## ⚙️ Kurulum ve Çalıştırma

1. Repoyu klonlayın:
```bash
git clone https://github.com/kaya-beyza/leydib-desserts.git
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Uygulamayı başlatın:
```bash
ng serve
```
